# Energon plugin (`energon`)

Install this plugin from **this Energon repo** (the fork you instantiated), not from a placeholder host. Claude Code and [Agent Plugins](https://agent-plugins.org/) hosts use the same marketplace. Install at user (global) scope unless the human asked for a project-level install.

After the host exists, mint a token at https://energon.example.com/tokens and export it as the env named in `GET https://energon.example.com/v1/help`.

Humans and agents: [INSTALL.md](../../INSTALL.md). Copy-paste prompts: [README.md](../../README.md).
