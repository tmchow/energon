Agent tokens

Let an agent publish, read, reference, or update work on your behalf. Configure it with __TOKEN_ENV__; updates follow each file or site's write policy. The secret is shown once when you mint. The list shows the last four characters.

A valid token can read work on this instance, including password-protected links. Token expiration stops agent access through that token; it does not expire published links. New here? Connect your agent.
