# Contributing

This repository is the Energon source you fork and run for yourself or your organization.
[getenergon.com](https://getenergon.com) explains the project; there is no hosted public service there.

**Issues are welcome. Pull requests are not.**

Unsolicited patches are not merged. Reviewing them takes more time than
this project can take. Please:

1. [Open an issue](https://github.com/tmchow/energon/issues/new/choose)
   for a bug or an idea. Include enough to reproduce. Do not paste tokens,
   Access credentials, or file contents that are not yours.
2. Fork the repo if you need a change on your Energon. Keep that work
   on your fork.
3. Do not open a pull request against `tmchow/energon` unless the owner
   asked for that patch.

A GitHub Action closes pull requests that come from forks.

Security reports: see [SECURITY.md](./SECURITY.md). Do not file those
as public issues.
