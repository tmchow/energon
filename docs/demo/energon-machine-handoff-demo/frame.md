# Visual direction

Concept angle: the same person crosses a real machine boundary by carrying one explicit Energon URL from a warm local desktop into a cool remote workspace.

- Focal element: the source ZIP and its complete URL, never an implied sync state.
- Machine distinction: warm Finder/Mac surfaces for local; cooler browser/IDE surfaces for remote.
- Identity: Maya's violet `M` avatar appears on both machines.
- Edge anchors: upper-left sequence label, upper-right device badge, lower-right Energon close.
- Background: deep aubergine, fine lavender grid, one restrained radial bloom.
- Depth: large framed application surfaces with soft violet shadows.
- Type: Montserrat for interface copy; IBM Plex Mono for paths, URLs, labels, and status.
- Motion: precise assembly, one deliberate copy action, connector draw, quiet proof holds.

## Palette

- Brand: `#17141f`, `#f8f5ff`, `#8a6cff`, `#b7a6ff`, `#d9d0ff`.
- Dark structure: `#211b30`, `#2a2535`, `#342044`, `#40344e`, `#514b59`.
- Light local surfaces: `#fffaf3`, `#f5eee7`, `#eadfd4`, `#403848`, `#746f7d`.
- Light remote surfaces: `#f8f6fb`, `#ece8f1`, `#ddd6e5`, `#24202d`, `#645e6d`.
- States: `#68bc8d`, `#dff2e7`, `#286143`, `#efc464`, `#d9ad4e`.

## Avoid

- No automatic-sync iconography or language.
- No second person, teammate, or Slack surface.
- No generic floating-card grid; every panel must read as a machine or artifact.
- No tiny URL, split word, or link abbreviation at the actual handoff beat.
