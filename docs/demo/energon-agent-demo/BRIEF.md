## Intent

Show one believable request moving all the way from an agent conversation to a
shared Slack channel and then to the published prototype. The result should make
Energon feel agent-native without hiding the concrete artifact it produces.

## Assets

- `assets/terminal.mp4` — deterministic VHS recording of the simulated Codex interaction.
- `assets/energon-logo.svg` — the repository's Energon mark, used as the visual handoff anchor.

## Notes

- This is a silent, simulated workflow for a GitHub README.
- Each scene must communicate one idea without relying on the previous scene's fine print.
- Hold the final prototype long enough to understand what the link delivered.
- Do not end on black or reset before the loop.
