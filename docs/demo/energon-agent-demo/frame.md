# Visual direction

Concept angle: one luminous Energon handoff travels through three familiar work
surfaces, turning a natural-language request into something a teammate can open.

- Focal element: the published link, repeated at the decisive moment in every scene.
- Edge anchors: an upper-left sequence label and lower-right Energon mark keep orientation stable.
- Supporting detail: restrained metadata, realistic channel and browser chrome, and one cursor actor.
- Background: deep aubergine with a lavender radial bloom, fine grid, and subtle grain.
- Depth: large framed app surfaces, soft violet shadows, and a foreground handoff rail.
- Type: Montserrat for interface copy and IBM Plex Mono for URLs, labels, and sequence metadata.
- Motion: mechanical, direct entrances; a precise click reaction; stillness for the final proof.
