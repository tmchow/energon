# Visual direction

Concept angle: one protected Energon document moves between two people and two
agents without losing its URL, its context, or human ownership of the decision.

- Focal element: the implementation plan, identifiable by title and stable URL in every handoff.
- Edge anchors: an upper-left sequence label and lower-right Energon mark preserve the first demo's rhythm.
- Supporting detail: realistic Claude Code, Codex, Slack DM, password gate, and rendered Markdown surfaces.
- Markdown cue: document typography, section rules, lists, and Mermaid flowcharts; never dashboard cards or a faux browser editor.
- Background: deep aubergine with a lavender radial bloom, fine grid, and restrained grain.
- Depth: large framed app surfaces, soft violet shadows, and foreground cursor actors.
- Type: Montserrat for interface copy and IBM Plex Mono for URLs, labels, and sequence metadata.
- Motion: mechanical entrances, deliberate cursor actions, quiet reading holds, and a final synchronized proof.
- Human signal: Maya and Noah are named at every decision point; agents execute their stated intent.
